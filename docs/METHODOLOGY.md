# Методика: признаки и расчёт риска

## Принцип

Система не объявляет схему незаконной. Она находит **признаки** возможного нарушения, показывает их с цитатами и вкладом в риск и ставит группу в очередь. Решение принимает специалист.

## Конвейер

```
экспорт чата / текст / скриншот
  → нормализация (казахский, транслит, маскировка, суммы, реквизиты)
  → признаки сообщения (объяснимые правила: что нашли, цитата, сила 0..1)
  → риск сообщения (логистическая регрессия, вклад каждого признака виден)
  → риск группы (роли, рассылки, реквизиты, хронология)
  → граф связей между группами (общие реквизиты, рассылки, ссылки, аккаунты)
  → очередь аналитика и отчёт
```

## 1. Нормализация

Признаки ищутся по «каноническому» тексту, поэтому одно правило работает на русском, казахском, смешанном языке и транслите.

| Что встречается в чатах | Что делает система |
|---|---|
| қ, ң, ә, ө, ұ, ү, і | сводит к к, н, а, о, у, у, и |
| Транслит: «vlozhi 5k poluchi 15k», «aqsha salsan», «dney», «uspey» | переводит в кириллицу, «y/i» после гласной — «й», «c» — «ц» |
| Латиница-двойники: «kаspi», «вл0жи», «пр!гласи», «м3сяц» | заменяет на кириллицу; «3» между согласными — «е», иначе «з» |
| Разрядка: «к а с п и», «к.а.с.п.и», «5 0 0 0», невидимые символы | склеивает |
| Суммы: «5к», «10 мың», «20 мыңнан», «бес мың», «пол-ляма», «10-15 мың», «1,5 млн» | приводит к числам |
| Проценты словами: «5 процентов», «3 пайыз» | превращает в «%» |
| Телефоны Kaspi, карты, IBAN, ссылки | извлекает отдельно, в интерфейсе маскирует |

## 2. Признаки сообщения

| Группа | Признак | Примеры | Как считается |
|---|---|---|---|
| Обещание | Нереалистичная доходность | «вложи 5 000 → получи 15 000 за 3 дня», «из 20к — 100к», «10к → 25к за неделю», «окупится за 3 дня» | пара сумм «вложить → получить» в предложении или двух соседних: кратность и срок; окупаемость не дольше 60 дней |
| | Высокий процент за короткий срок | «3% в день», «30% в месяц», «2 000 в день на вложение 20 000», «через 15 дней доход 100%», «бонус +50% к вкладу», «оборот 30%» | пересчёт в процент в день; признак — от 0,3% в день (это больше 100% годовых) |
| | Обещание умножить деньги | «x3», «удвоим», «в двойном размере», «екі есе» | только рядом с деньгами; «в 2 раза дешевле», «бонусы х2» не считаются |
| | Заявления о доходе | «зарабатываю 25 000 в день», «доход с одного вложения», «күніне 15 мың табамын» | |
| | Призыв вложить | «вкладывай от 5 000», «вложи в наш проект», «VIP-пакет за 10 000 — и задания приносят…», поддельные «государственные платформы» | платный вход за «задания» и «проект» — сильнее, просто «вклад 5 000» — слабее |
| | Гарантия, лёгкий доход, «это не пирамида» | «гарантированно», «без риска», «пассивный доход», «бәрі адал» | «это не пирамида?» с вопросом — уже сомнение |
| Давление | Дефицит, срочность, эмодзи | «осталось 2 места», «поток закрываем», «бүгін ғана», 🔥💰 | |
| Вербовка | Доход за приглашённых | «10% с вкладов приглашённых», «бонус за каждого, кто вложит», «2 адам әкел» | приглашение на той или «пригласите соседа» не считается |
| | Многоуровневая структура | «1 линия 10%, 2 линия 5%», «матрица», «под тобой 6 ячеек» | |
| | Круг, ячейка, очередь | «касса взаимопомощи», «цветок: огонь → вода», «ұяшық», «переводишь первой в списке», «деньги от новых участников» | |
| Оплата | Перевод на личную карту, Kaspi | реквизиты, «по номеру», «каспиге аудар» | «пишите в лс» перевода не означает |
| Подтверждения | «Отзыв» о выплате | «вывела 45к, всё честно», «4-ші выплата», «ақша түсті» | «спасибо организаторам свадьбы» — нет, рядом должны быть деньги |
| Снижают риск | Предупреждение, новость, суд | «не ведитесь», «АФМ предупреждает», «вынес приговор», «үкім шықты» | |
| | Обещание в цитате или пересказе | «ходит сообщение «вложи 5000…» — это пирамида», «маме обещали 3% в день», «люди надеялись получить 100%» | сила всех признаков схемы в таком сообщении умножается на 0,35 |
| | Сомнение, вопрос | «это развод?», «қауіпті емес пе?» | |
| | Легальный финпродукт | «16% годовых», депозит, рассрочка, банк | не действует, если обещан нереальный процент |
| | Награда не деньгами, законные выплаты | скидка, бонусы на заказ; зарплата, пособие, АСП, аренда | |

## 3. Риск сообщения

Риск = σ(b + Σ wᵢ·xᵢ), где xᵢ — сила признака от 0 до 1, плюс обобщённые признаки («есть обещание», «есть вербовка») и сочетания («доходность + перевод на карту»). Вклад признака wᵢ·xᵢ аналитик видит в блоке «Почему помечено».

Как обучена модель:

- логистическая регрессия на синтетической обучающей выборке (1 760 сообщений), L2-регуляризация, балансировка классов;
- **знаки весов закреплены:** признак схемы может только повышать риск, снимающий — только понижать, поэтому объяснение никогда не противоречит смыслу признака;
- **«выпадение признаков»:** к каждому примеру со схемой добавлены копии, где часть признаков случайно «не нашлась». Модель узнаёт схему и по одному-двум признакам — так бывает на незнакомой формулировке;
- **пороги** подобраны на рукописных настроечных наборах (694 сообщения): средний риск — от 49% (лучший F1 при точности не ниже 95%), высокий — от 57% (точность не ниже 98%).

Самые сильные веса: «есть обещание дохода» +1,82, «призыв вложить» +1,61, «отзыв о выплате» +1,39, «есть вербовка» +0,96, «нереалистичная доходность» +0,80. Снижают: «награда не деньгами» −1,26, «обещание в цитате» −1,08, «предупреждение» −0,88, «законные выплаты» −0,85. Полная таблица — во вкладке «Как это работает» дашборда.

Пороги группы: средний риск — от 50%, высокий — от 75%. Итоговая фраза собирается из самых сильных признаков: «Обнаружены признаки финансовой пирамиды: … Требуется проверка специалистом».

## 5. Граф связей

Группы связываются через общие сущности: реквизиты (телефон Kaspi, карта, IBAN), одинаковые рекламные рассылки, домены ссылок и аккаунты Telegram, которые продвигали схему. Компонента связности из двух и более групп — «сеть»: её показывают с перечнем связей («один и тот же реквизит — в 3 группах»).

## 6. Мультимодальность

- **Скриншоты** чеков и переписок распознаются (tesseract.js, русский и казахский). Скриншот выплаты сам по себе — признак «прогрева».
- **Голосовые и стримы** — в плане: распознавание речи, затем тот же конвейер.

## 7. Данные и разметка

| Набор | Размер | Зачем |
|---|---|---|
| Обучающий | 1 760 сообщений, 90 чатов | синтетика по шаблонам с маскировкой, воспроизводимая (фиксированное зерно) |
| Настроечные dev, dev2, dev3 | 294, 200, 200 сообщений | по ним разбирались ошибки и подбирались пороги |
| Слепой тест | 200 сообщений, 24 чата | итоговые метрики |
| Реальные тексты | 61 (18 зазывающих, 43 обычных) | цитаты из СМИ и сообщений АФМ |

**Правило разметки.** Сообщение — «схема», если по нему одному видно хотя бы один признак: обещание дохода от вложения, награда за привлечение вкладчиков, «отзыв» о выплате, круг или ячейка, платный вход за задания, призыв перевести деньги ради прибыли, поддельная государственная платформа. Предупреждения и новости, которые цитируют обещания, вопросы «это развод?», сборы денег, депозиты, сетевой маркетинг, реферальные программы магазинов, вакансии — «обычные». Сообщения без денежного контекста («Осталось 2 места!») оцениваются только в составе группы.

## 8. Как проверяли — честно

Каждый слепой набор составлял отдельный исполнитель (ИИ-агент), который не видел ни кода, ни правил, ни обучающих данных. Перед прогоном модель замораживалась: хэши файлов модели и правил записаны в `reports/freeze.json`. После прогона набор разбирался по видам ошибок и переходил в настроечные, а следующую проверку делал новый слепой набор.

| Проверка | n | Precision | Recall | Ложные срабатывания |
|---|---|---|---|---|
| Тест №1, написан вручную | 130 | 94,1% | 53,3% | 2,9% |
| Тест №2, независимый исполнитель | 200 | 81,1% | 81,1% | 15,5% |
| Тест №3, независимый исполнитель | 200 | 87,7% | 78,9% | 9,1% |
| Реальные тексты, первый прогон | 61 | 66,7% | 22,2% | 4,7% |
| **Итог: тест №4** | **200** | **87,2%** | **91,1%** | **10,9%** |

Для сравнения — поиск по ключевым словам (так обычно работает ручной мониторинг): точность 50,9%, полнота 63,3%, ложные срабатывания 50,0%.

**Группы целиком** (слепой набор, 12 экспортов WhatsApp и Telegram, та же замороженная модель): все 6 пирамид найдены; из 6 обычных групп одна — обсуждение финансов — помечена средним риском. Точность 85,7%, полнота 100%, ложные 16,7%. Поиск по ключевым словам пометил все 12 групп.

## 9. Ограничения

- Слепые наборы синтетические, их писали ИИ-агенты. Цифры на реальных жалобах нужно подтвердить на пилоте.
- Одно сообщение без денег («Осталось 2 места! Успевайте») по себе не определяется — его видно в составе группы.
- Короткие названия чатов и лозунги без условий («Касса от ставки») система пропускает.
- Формулировки схем меняются: правила и веса обновляются по решениям аналитиков, у каждой версии — проверка на свежем слепом наборе.
