# SafeNet KZ · Стоп-пирамида

Система находит в группах WhatsApp и Telegram признаки финансовых пирамид — на русском, казахском, смешанном языке и транслите — и ставит группы в очередь на проверку специалисту.

Автор: Элмуратов Мадияр. Хакатон SafeNet KZ, трек «Стоп-пирамида».

- Презентация: https://claude.ai/artifact/QH4x6Kmav5gzfPZSmUaLcj
- Методика и метрики: [docs/METHODOLOGY.md](docs/METHODOLOGY.md) · План внедрения: [docs/PLAN.md](docs/PLAN.md) · Сценарий питча: [docs/PITCH.md](docs/PITCH.md)

**Итог на слепом наборе** (200 сообщений, модель заморожена до прогона): точность 87,2%, полнота 91,1%, F1 89,1%, ложные срабатывания 10,9%. У поиска по ключевым словам — 50,9%, 63,3%, 56,4% и 50,0%.

**Принцип:** система не объявляет схему незаконной. Она показывает признаки возможного нарушения, объясняет, почему контент помечен, и оставляет решение человеку.

## Запуск

Нужен Node.js 24 или новее. Сборки нет — TypeScript выполняется напрямую.

```bash
npm install
npm start
```

Откройте http://127.0.0.1:3600.

## Что показать на демо

- **Очередь.** Шесть синтетических групп: три пирамиды (русская, казахская, «касса взаимопомощи») и три обычные (родительский чат со сбором денег, магазин с розыгрышем, финансовый чат с предупреждениями). Пирамиды наверху. В карточке группы — риск и итоговая фраза, четыре главных факта (обещание, реквизиты, связанные группы, сколько помечено) и вкладки «Почему помечено», «Сообщения», «Участники и реквизиты».
- **Сеть связей.** Три пирамиды связаны общим номером Kaspi, картой и одинаковой рассылкой — это одна сеть организаторов.
- **Проверить текст.** Вставьте любое сообщение или экспорт чата. Есть примеры с маскировкой: «к а с п и», «вл0жи», «5 мың салсаң».
- **Загрузить чат или скриншот.** Экспорт WhatsApp (.txt), Telegram Desktop (result.json) или скриншот: текст распознаётся (русский и казахский). Пример скриншота выплаты — `data/demo-images/vyplata.png`.
- **Точность.** Слепая проверка против поиска по ключевым словам, по языкам, по группам целиком, история проверок.
- **Как это работает.** Шаги обработки, как считается риск, веса всех признаков.

Ссылки на вкладки: `/#graph`, `/#check`, `/#metrics`, `/#method`; `/#check:<текст>` сразу проверяет текст.

## Как повторить обучение и метрики

```bash
node scripts/generate-dataset.ts   # синтетическая обучающая выборка: 1 760 сообщений и 90 чатов
node scripts/train.ts              # модель сообщений (пороги — по рукописным data/dev*)
node scripts/train-chats.ts        # модель групп
node scripts/eval.ts test          # слепой тест сообщений → reports/message-metrics-test.json
node scripts/eval-chats.ts test    # слепой тест групп → reports/chat-metrics-test.json
npm run typecheck
```

## Устройство

| Папка | Что внутри |
|---|---|
| `src/normalize.ts` | Нормализация: казахские буквы, транслит, маскировка, суммы, реквизиты и ссылки |
| `src/signals.ts` | Признаки сообщения — объяснимые правила с цитатой и силой |
| `src/model.ts` | Логистическая регрессия над признаками, вклад каждого признака |
| `src/chat.ts` | Анализ группы: роли, шаблонные рассылки, реквизиты, хронология, итоговая фраза |
| `src/graph.ts` | Граф связей между группами |
| `src/ocr.ts` | Распознавание скриншотов (tesseract.js, rus + kaz) |
| `src/server.ts` | API и дашборд аналитика |
| `public/` | Дашборд |
| `data/train` | Синтетическая обучающая выборка (генерируется) |
| `data/dev`, `data/dev2` | Рукописные настроечные наборы — по ним разбирались ошибки |
| `data/test` | Слепые наборы сообщений и чатов — итоговые метрики |
| `data/real` | Тексты из открытых источников (СМИ, сообщения АФМ) |
| `docs/` | Методика, план внедрения, сценарий питча |

## Данные и этика

Используются только синтетические данные и тексты из открытых источников; имена, телефоны и карты — выдуманные или обезличенные. В интерфейсе реквизиты маскируются. Система не обвиняет, а помечает контент для ручной проверки и не помогает организовывать схемы.
